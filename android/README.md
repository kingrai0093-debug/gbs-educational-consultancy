# GBS Educational Consultancy - Official Android App

Official native Android application wrapper for **GBS Educational Consultancy** with optimized WebView, hardware acceleration, full offline recovery, pull-to-refresh, dialer and file upload support.

## App Specifications:
- **Package Name**: `com.gbs.consultancy`
- **Application Name**: GBS Educational Consultancy
- **Live URL**: `https://kingrai0093-debug.github.io/gbs-educational-consultancy/`
- **App Icon**: Generated directly from `web-logo.jpg` (Full Mipmap Suite + Play Store 512x512)
- **Min SDK**: API 24 (Android 7.0+)
- **Target SDK**: API 34 (Android 14+)

## Included Features:
1. 🚀 **Instant Loading & Splash Screen**: Fast-launch branded splash screen featuring the official GBS logo.
2. 🔄 **Swipe-to-Refresh**: Native pull down anywhere to refresh the latest Korean university intakes and ticker bulletins.
3. 📱 **Deep Links & Phone Intent**: Direct tap-to-call on counselor hotlines (`tel:9744427779`) and instant WhatsApp chat opening.
4. 📄 **Document Upload Support**: WebChrome file chooser enables student academic transcript & passport photo uploads.
5. 📶 **Offline State Detection**: Elegant offline screen with 1-tap retry when network is restored.
6. 🔙 **Smart Back Navigation**: Hardware back button navigates web history before exiting.

## How to Build in Android Studio:
1. Open **Android Studio**.
2. Select **Open an Existing Project** and choose the `android` directory in this repository.
3. Wait for Gradle sync to complete.
4. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)** to generate the debug or release `.apk`.
